# AI Companion Legal Site

Ready-to-publish static GitHub Pages site containing:

- `index.html`
- `privacy.html`
- `terms.html`
- `style.css`

## Before publishing

Replace every occurrence of:

`CONTACT_EMAIL_HERE`

with a real email address you monitor for privacy/deletion requests.

## GitHub Pages

1. Create a public GitHub repository, e.g. `ai-companion-legal`.
2. Upload these files to the repository root.
3. Open **Settings -> Pages**.
4. Choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**.
6. Save and wait for deployment.

Your URLs will typically be:

- `https://YOUR_GITHUB_USERNAME.github.io/ai-companion-legal/privacy.html`
- `https://YOUR_GITHUB_USERNAME.github.io/ai-companion-legal/terms.html`

Paste those into Discord Developer Portal -> General Information.
